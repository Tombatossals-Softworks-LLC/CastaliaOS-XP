# Castalia OS — Press Kit

Everything a journalist, blogger or reviewer needs to write about **Castalia
OS**, in one folder. All text is free to quote; all images are cleared for
editorial use (see `CREDITS-and-LEGAL.md`). Nothing here is under embargo.

> **Castalia OS** is an original, legally-clean, XP-class desktop operating
> system that makes early- and late-2000s PCs feel fast, modern and cared-for
> again. Built from scratch by **Tombatossals Softworks**.

**A single-page version of this kit:** open [`index.html`](index.html) in any
browser (self-contained, works offline).
