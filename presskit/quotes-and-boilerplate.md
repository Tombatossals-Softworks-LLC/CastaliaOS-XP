## Boilerplate (put this at the foot of an article)

*Castalia OS is an original, legally-clean desktop operating system for early-
and late-2000s PCs, built from scratch by independent studio Tombatossals
Softworks. It pairs a de-systemd'd Debian base with a custom Qt/C++ desktop
shell, 46 first-party applications, a seven-theme design system and a managed
Windows/DOS/ScummVM compatibility layer — and runs, in full, on machines with
as little as 512 MB of RAM. Learn more at https://tombatossalssoftworks.com.*
