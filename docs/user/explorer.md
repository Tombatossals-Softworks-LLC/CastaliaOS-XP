# Castalia Explorer

*Verificado en la versión 0.1.1.*

El explorador de archivos. Se abre con **Súper+E**, desde el menú, o al hacer
doble clic en una carpeta del escritorio.

## Lo que hay en la ventana

| Parte | Qué es |
|---|---|
| Barra de direcciones | dónde estás; se puede escribir una ruta y pulsar Intro |
| Panel lateral | los sitios habituales: Mis documentos, Escritorio, Papelera, el disco |
| Lista | los archivos, con nombre, tamaño, tipo y fecha |
| Barra de estado | cuántos elementos hay y cuánto ocupan |

## Lo que se puede hacer

- **Abrir**: doble clic. Un archivo se abre con el programa que le
  corresponda según *Programas predeterminados* (Centro de control).
- **Copiar, cortar, pegar**: `Ctrl+C`, `Ctrl+X`, `Ctrl+V`, como en todas
  partes.
- **Renombrar**: `F2`.
- **Enviar a la papelera**: `Supr`. **Borrar del todo**: `Mayús+Supr`, con
  confirmación, porque eso no se puede deshacer.
- **Subir un nivel**: `Alt+Flecha arriba`. **Atrás**: `Alt+Flecha izquierda`.

## La papelera

`Supr` no borra: mueve a la papelera, que es una carpeta como cualquier otra
y se puede abrir desde el panel lateral o desde el menú. Ahí dentro se puede
restaurar un archivo a donde estaba o vaciarla del todo.

Un archivo en la papelera **sigue ocupando disco**. Si estás quedándote sin
espacio, vaciarla es lo primero que hay que probar.
