# Manual de usuario de Castalia OS

*Verificado en la versión 0.2.0.*

Este manual describe **lo que hay hoy en el sistema**, no lo que está
planeado. Si algo aparece aquí, existe y se puede usar.

## Lo primero que conviene saber

**Castalia no es Windows y no pretende engañarte.** Se parece a propósito, y
donde no puede hacer lo mismo lo dice en vez de fingirlo. Cuando una
aplicación de Windows no funcione bajo Wine, el [Administrador de aplicaciones
de Windows](../wine/README.md) te dirá por qué y con qué nota, no te dejará
adivinando.

**Tus archivos están en `/home/tu-usuario`.** El Explorer lo abre en «Mis
documentos». Nada de lo que hace el sistema — ni una restauración, ni una
actualización — toca esa carpeta.

**Funciona sin internet.** El instalador, la ayuda y el sistema de
recuperación son completos en el disco. No hay ninguna pantalla que se quede
esperando a una conexión.
