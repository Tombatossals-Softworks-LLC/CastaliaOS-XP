# Las aplicaciones

*Verificado en la versión 0.1.1.*

Todas están en el menú Inicio. Todas son originales de Castalia salvo donde se
diga lo contrario.

## Trabajo

| Aplicación | Qué es |
|---|---|
| Notas | editor de texto plano |
| Escritor | editor con formato (negrita, listas, tablas) |
| Notas adhesivas | notas pegadas al escritorio |
| Calculadora | normal y científica |
| Mapa de caracteres | para los caracteres que no están en el teclado |
| Calendario | mes, año, y las notas del día |
| Reloj | reloj, alarma, cronómetro |

## Imagen y sonido

| Aplicación | Qué es |
|---|---|
| Visor de imágenes | ver, girar, pase de diapositivas |
| Pintura | dibujo sencillo, mapa de bits |
| Reproductor multimedia | audio y vídeo |
| Captura de pantalla | pantalla entera, ventana o zona |

## Archivos y sistema

| Aplicación | Qué es |
|---|---|
| Castalia Explorer | el explorador de archivos |
| Buscar archivos | buscar por nombre, tipo, fecha o contenido |
| Papelera de reciclaje | lo borrado, recuperable |
| Archivos comprimidos | zip, tar, gz |
| Terminal | la línea de órdenes |
| Ejecutar… | lanzar un programa por su nombre |
| Monitor del sistema | procesos, memoria, CPU |
| Visor de registros | los logs del sistema, en texto y en lenguaje llano |
| Administrador de discos | qué discos hay y cuánto queda libre |
| Centro de hardware | qué piezas detectó el sistema y qué controlador usan |
| Servicios del sistema | los servicios de arranque, en lenguaje llano |
| Diagnóstico del sistema | comprobaciones rápidas cuando algo va mal |
| Historial de notificaciones | los avisos que ya se cerraron |

## Configuración

| Aplicación | Qué es |
|---|---|
| Centro de control | la configuración, en un sitio |
| Cuentas de usuario | usuarios y contraseñas |
| Fecha y hora | reloj y zona horaria |
| Control de volumen | volumen y dispositivos |
| Centro de redes | conexiones |
| Impresoras | impresoras y trabajos |
| Programas predeterminados | qué abre cada tipo de archivo |
| Teclado en pantalla | para tocar sin teclado, o cuando el teclado falla |
| Lupa | ampliar una zona de la pantalla |

## Mantenimiento

| Aplicación | Qué es |
|---|---|
| Centro de software | instalar y quitar programas |
| Centro de actualizaciones | actualizar el sistema |
| Centro de recuperación | puntos de restauración |
| Asistente de migración | traer documentos y ajustes de otro sistema |
