# El Centro de control

*Verificado en la versión 0.2.0.*

Menú → **Centro de control**. Nueve secciones, en la lista de la izquierda.

| Sección | Qué se toca ahí |
|---|---|
| **Apariencia** | el tema (los siete), el fondo de escritorio |
| **Pantalla** | resolución y frecuencia; prueba antes de aplicar |
| **Salvapantallas** | cuál, cada cuánto, y si pide contraseña al volver |
| **Sonido** | volumen, dispositivo de salida, el juego de sonidos del sistema |
| **Red** | conexiones por cable y Wi-Fi |
| **Energía** | qué hacer al cerrar la tapa, apagado de pantalla |
| **Recuperación** | los puntos de restauración (ver más abajo) |
| **Idioma** | idioma del sistema y distribución de teclado |
| **Acerca de Castalia** | versión, licencia, el aviso de no afiliación |

## Un detalle sobre Pantalla

Cambiar la resolución **prueba primero y pregunta después**: aplica el modo
nuevo, muestra una cuenta atrás, y si no confirmas vuelve al modo anterior.
Eso existe porque en una pantalla vieja un modo que no soporta no da un error,
da una pantalla negra — y en una pantalla negra no se puede pulsar «deshacer».

## Recuperación

Esta sección lista tus **puntos de restauración**: fotos del estado del
sistema que se pueden volver a poner si algo se rompe. Se explica entero en la
[Guía de recuperación](../recovery/README.md).

Lo importante en una frase: **restaurar no toca tus archivos personales.** Un
punto de restauración guarda el sistema, no tu `/home`.
