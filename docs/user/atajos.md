# Atajos de teclado

*Verificado en la versión 0.1.1.*

Estos son los atajos **globales**: funcionan estés donde estés. Vienen de
`shell/session/openbox-rc.xml`, que es el único sitio donde se definen.

## Sistema

| Atajo | Qué hace |
|---|---|
| **Súper** | abrir el menú Inicio |
| **Súper+E** | Castalia Explorer |
| **Súper+R** | Ejecutar… |
| **Súper+T** | Terminal |
| **Súper+F** | Buscar archivos |
| **Súper+L** | bloquear la pantalla |
| **Súper+D** | mostrar el escritorio (minimizar todo) |
| **Súper+Escape** | Salir de Castalia (cerrar sesión, apagar, reiniciar) |
| **Ctrl+Alt+Supr** | Monitor del sistema |
| **F1** | Centro de ayuda |
| **Impr Pant** | Captura de pantalla |

## Ventanas

| Atajo | Qué hace |
|---|---|
| **Alt+F4** | cerrar la ventana |
| **Alt+F7** | mover la ventana con las flechas |
| **Alt+F9** | minimizar |
| **Alt+Tab** | cambiar de ventana |

## Volumen

Las teclas de volumen del teclado (subir, bajar, silenciar) abren el **Control
de volumen** si tu teclado las tiene.

## Por qué la tecla Súper y no otra

Es la tecla que en un teclado de la época lleva el logotipo de Windows. En
Castalia abre el menú de Castalia. Eso es deliberado: la memoria muscular de
quien viene de aquella época es un activo, no algo que haya que reeducar.
