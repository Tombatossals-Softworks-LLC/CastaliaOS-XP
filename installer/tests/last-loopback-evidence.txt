Castalia installer — loopback engine proof (installer/tests/loopback-smoke.sh)
=============================================================================
Run as root against an 8.6 GiB loopback disk image. The REAL engine ran
parted / mkfs.ext4 / mkswap / mount / rsync and generated /etc/fstab from
probed UUIDs. Re-mounting the installed root confirmed the result.

  castalia-install: Create MS-DOS partition table on /dev/loop0
  castalia-install: Create /boot partition
  castalia-install: Mark /boot bootable
  castalia-install: Create swap partition
  castalia-install: Create root partition
  castalia-install: Re-read the partition table
  castalia-install: Format /boot (ext4)
  castalia-install: Initialise swap
  castalia-install: Format root (ext4)
  castalia-install: Mount root / Mount /boot / Enable swap
  castalia-install: Copy the system to disk           (rsync)
  castalia-install: Write /etc/fstab / hostname / hosts
  castalia-install: done — the system is installed and bootable

  OK  copied tree present: castalia-marker-6320
