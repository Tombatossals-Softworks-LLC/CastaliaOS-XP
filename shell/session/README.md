# castalia-session — user session manager

Launched by the greeter via [`castalia.desktop`](castalia.desktop). Implements
the Bible §7.1 process model in POSIX sh (§12): the window manager and each
shell process run **supervised** — a crash restarts in ~1 s and never blacks
out the desktop — and SIGTERM tears the session down cleanly (logout).

| Responsibility | How |
|---|---|
| Theme | Reads the active theme id from `~/.config/castalia/theme.conf` (fallback `/etc/castalia/theme.conf`, then `classic`); exports `CASTALIA_THEME`; Openbox picks up the `Castalia-<id>` theme generated by `tools/theme_export.py` |
| Startup order | Openbox first (windows always manageable), then `castalia-panel`; `castalia-desktop` joins in Phase 2 (§18) |
| Supervision | `supervise()` loop per process, 1 s backoff, stop-flag aware |
| Logout | SIGTERM/SIGINT → stop flag + child teardown → clean exit |

Phase 0 skeleton: session D-Bus/elogind integration, autostart entries, and
lock-on-idle arrive with Phase 2.
